# Примеры для публичного лендинга

Edzz, первый раунд на Ancient: четыре убийства из USP-S, четыре попадания
в голову. Отдельные сжатые копии готовых клипов RecoilSnap, опубликованные
как примеры по запросу владельца проекта. Доступны без входа; ссылки на
закрытое API, токены и сведения об аккаунтах сюда не переносятся.

| Файл | Исходный фрагмент | Формат |
|---|---|---|
| `wide.mp4` | `frag_1793488940892_e92637` | 16:9, без HUD |
| `square.mp4` | тот же широкий клип | 1:1, центральная обрезка |
| `vertical.mp4` | `frag_1793540069437_6e013c` | настоящий вертикальный рендер 9:16 |
| `blur.mp4` | тот же широкий клип | 9:16, полный кадр на размытом фоне |

H.264, 30 fps, CRF 25, AAC 96 kbit/s, длинная сторона до 960 px
(квадрат — 720×720), `-movflags +faststart`, исходные метаданные удалены.
JPG-постеры — кадр на 17.5 секунде, во время перестрелки. Версия в URL
`?v=edzz-4k` обновляет браузерный кэш при замене прошлых примеров.
При деплое копировать каталог вместе с `index.html`.
