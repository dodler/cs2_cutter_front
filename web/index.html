Рендер-хосты

Машины с CS2 (cs2_cutter), между которыми раскидываются задачи: новая демка уходит на готовый хост с самой короткой очередью, задачи по ней — туда же. На хосте CS2_JWT_SECRET должен совпадать с библиотекой, CS2_LIBRARY_URL — указывать на неё, а в CS2_CORS_ORIGINS — быть адрес этого UI.
