Рендер-хосты

Машины с CS2 (cs2_cutter), между которыми раскидываются задачи: новая демка уходит на готовый хост с самой короткой очередью, задачи по ней — туда же. На хосте CS2_JWT_SECRET должен совпадать с библиотекой, CS2_LIBRARY_URL — указывать на неё, а в CS2_CORS_ORIGINS — быть адрес этого UI.

Подключить новый хост

Библиотека сама зайдёт на машину по SSH, поставит пакеты и Steam, войдёт в Steam, скачает CS2, поднимет сервис рендера и добавит хост в список выше. Рассчитано на инстанс vast.ai (Ubuntu, вход root, порт 8000 проброшен наружу). Сначала добавьте на машину SSH-ключ библиотеки.

Пароль Steam не сохраняется: он нужен один раз для входа на хосте, дальше Steam помнит вход сам. Аккаунт должен быть свой у каждого хоста — одна и та же CS2 на двух машинах выкидывает друг друга.
